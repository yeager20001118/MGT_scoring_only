GOAL
Produce DetectGPT + NPR score files for 5 source LLMs (claude_sonnet_4.6, claude_opus_4.5,
claude_haiku_4.5, gpt4o_mini, gemini_3.1_flash) under the proxy models listed in
code/run_scoring.py, for both datasets (olympic, xsum). Outputs go to scoring_results/ as
<dataset>.<source>.<proxy>.{perturbation_30,npr}.json.

WHAT TO DO
1. Create the env (env/environment.yml), then install the torch build that matches THIS
   server's CUDA/ROCm version (do not assume the default wheel). Verify transformers >= 4.50.
2. Download the proxy models: `python models/download_proxies.py --list` first, CONFIRM the
   HF repo IDs in PROXY_REPOS look right for this project (especially gemma-3-*), then
   download. Gemma-3 and Llama-3 are gated — log in with a token whose account accepted the
   licenses. Models must land at models/cache/local.<proxy>/.
3. Dry-run: `python code/run_scoring.py --list`.
4. Score: `python code/run_scoring.py --gpu 0` (shard by proxy across GPUs with --proxies if
   you have several; add --fp16 on memory-tight GPUs). Start with gemma3_4b,gemma3_12b — they
   give the largest signal — before spending time on the rest.
5. Verify with `python code/run_scoring.py --list` (all cells detgpt=OK npr=OK).
6. `tar czf scoring_results.tar.gz scoring_results/` and hand it back.

HARD CONSTRAINTS
- Do NOT regenerate perturbations and do NOT download t5-3b. The perturbation caches already
  ship in data/raw_data/ and are reused automatically. You only run per-proxy scoring passes.
- Do NOT rename output files — the project keys on the exact
  <dataset>.<source>.<proxy>.<detector>.json pattern.
- The scorer is idempotent; re-running is safe and skips finished cells.
- falcon_40b is ~90GB — only run it if this GPU can hold it; otherwise skip it.
- If any proxy's HF repo id is uncertain, STOP and ask me rather than substituting a different
  model — a wrong checkpoint silently corrupts the AUROC.

REPORT BACK when done: which proxies you scored, any skipped/failed cells, the torch +
